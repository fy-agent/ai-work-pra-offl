# 附录 B · 双工具操作卡

同一件练习，可以在两个工作台上各跑一次。比较的是：材料有没有进去、数字能不能回原件、失败时会不会编。不要比较哪家更聪明。

入门只用你当天实际装着的工具。没有第二套，就只填一栏，不要抄别人的旧截图。

## 同一道练习题

材料：一份本月数字表，一份上月结构样例（虚构即可）。

任务四句：

1. 只读这两份材料  
2. 数字只来自本月表，对不上写待确认  
3. 交一份能打开的一页稿，或先只读出三个数字  
4. 不要发给任何人  

核对：场次、费用、人数能否回表；样例三块标题是什么。本指南虚构表里是 6 场、12,400 元、36 人；三块是结果、风险、下周。你换自己的表，以你的原件为准。

## 对照时看什么

| 看 | 不要看 |
| --- | --- |
| 工作根 / 空间是不是练习夹 | 模型广告名 |
| 读文件成功还是报不存在 | 哪次回答更长 |
| 失败后是停问还是编一份稿 | 积分、倍率 |
| 有没有写出练习夹以外的文件 | 哪边「更高级」 |

## 2026-08-20 实跑（会过期）

**WorkBuddy 桌面版 v5.3.14**  
新建任务，把四句贴进输入框，点发送。左栏出现任务，中间出现准备中、深度思考、读取中，发送键变成停止。它去读文件，工作副本里找不到练习夹，停下来问路径，**没有编月报**。同日还看到：选择工作空间、默认权限、@ 引用、/ 技能。

**Codex CLI 0.147.0**（另有桌面入口 Codex.exe）  
把工作根指到练习夹，沙箱设为只读，非交互跑同一道「只读、列出三个数字和三块标题、不写文件、不发送」。它读了表和样例，答出 6、12,400、36 和「结果 / 风险 / 下周」，**没有写新文件**。

两套都对得上第 14 章：工具在跑；材料不在空间里就会失败；失败不该改用编造。差别主要在你有没有把练习夹交给它当工作根。

命令名、窗口词、版本号明天可能改。只把「工作根、只读、停问」带回主文。

入门不要开「跳过全部确认、无沙箱」这类开关。那是给已经外层隔离的环境用的，不是练习默认。

## 你自己填的当天卡

不要把账号、密钥、绝对路径提交回本仓库。

```text
日期：

工具甲：
怎么打开：
工作根 / 空间怎么选：
这次读文件：成功 / 失败（原因）
有没有编数字：
有没有外发：

工具乙（没有就写无）：
怎么打开：
工作根 / 空间怎么选：
这次读文件：成功 / 失败（原因）
有没有编数字：
有没有外发：

同一道题，两边产物差在哪（只写能回原件的差）：
```

两边都失败，先修空间和材料，再换模型。两边数字打架，以原件为准，不以「更新的那次生成」为准。
