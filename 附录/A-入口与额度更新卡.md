# 附录 A · 入口与额度更新卡

主文不写死按钮位置、套餐名、价格和额度。那些东西会变。开用前自己填一张当天的卡。

不要把填好的真实账号、账单、邀请码提交回本仓库。

```text
日期：

我用的工作台：

打开方式（应用 / 网页 / 编辑器插件，选实际有的）：

登录用的是个人账号还是机构席位：

今天能做：读文件 / 改文件 / 联网  （以实际权限为准）

今天不能做：

额度或用量在哪看：

额度不够时会发生什么（停 / 排队 / 另计费，选你看到的）：

我准备用来练习的文件夹：

练习材料是否有权使用：是 / 否
```

没有的项就写「当天界面没找到」，不要抄别人的旧教程凑。

主文里说的「三个区」「发送给工作台不是发给同事」，要靠你在这张卡对应的软件上自己指一遍。指不上，先不要开始改正式文件。
