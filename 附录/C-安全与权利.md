# 附录 C · 安全与权利

## 练习材料

只用：

- 本指南里的虚构人物和虚构文件；或
- 你自己有权使用、并且可以放进该工作台的材料。

不要用：客户原件、同事未同意的聊天记录、合同、工资、身份证、未脱敏的财务报表、你没有发布权的文稿。

## 不要做的事

- 共享账号、出借登录态、代管别人的密钥
- 来源不明的代充、转卖 API Key
- 让工作台自动发送邮件、自动发消息到群、自动付款、自动发布内容
- 批量删除真实文件当练习
- 把待确认写成既成事实，再发给真实的人

入门练习停在：生成文件、打开、检查、改一处、保存在本地。外发是你自己的另一次决定。

## 工作台权限

第一次练，单独建文件夹。原件放进去之前先复制一份。不要把整个磁盘、整个公司网盘授权给一次入门练习。

它提出要覆盖原件、连接外部邮箱或网盘时，先停。入门阶段用「写新文件」就够。
