# 3.2 先问三句

## 这节解决什么问题

知道任务没说清，可一上手就填一张大表。表还没填完，已经不想写了。先用三句挡住最粗的漏。

## 先记住什么

先记三问，不要先背七段：

1. **说什么？** 要它做什么事。
2. **说到什么程度？** 给谁、根据什么、交成什么样。
3. **怎么知道说清楚了？** 另一人只看这段话，能不能说出要交什么；做完哪几项能打勾。

三问是自检。过不了再进入下一节的七个问题。七个问题是检查表，不是本指南的主题，也不用当填空卷背诵。

「专业、全面、高质量、好看一点」不算说到程度。那些词打不了勾。

## 当场怎么做

把这句拿来问三遍：

> 帮我根据这份会议记录做一个汇报。

写在纸上或一个 `任务卡.md` 里：

- 说什么：
- 说到什么程度：
- 怎么知道说清楚了：

如果你写「做一个汇报 / 专业一点 / 看起来像样」，三问都没过。改到至少出现：给谁、什么文件、不能做什么。

找一个没参加那次会的人（或过一天的自己），只把你写的三行给他看，问：「最后会交什么？」对方说不出文件名或长度，就还没说清楚。

## 怎么检查

过：三行都能指向可见结果；没有靠形容词充数；另一个人能说出要交的东西。

返工：第三问写的是「我觉得清楚了」；或仍然只有「做个汇报」。

## 常见翻车

把三问理解成写作文：每问写一小段排比。一问一行就够。

把「说到什么程度」理解成把提示词写长。长和清楚不是一回事。堆了 20 个必须、务必，还是可能没说文件名。

## 最小例子

李明改完的三行：

- 说什么：根据这份会议记录，给主管准备会前材料。
- 说到什么程度：一页；决定、待确认、行动项分三块；预算没批的保持待确认。
- 怎么知道说清楚了：文件叫 `复盘会前材料_v1.docx`；同事只看这三行，能说出「一页、三块、不把预算写成已落实」。

这三行还不算完整任务卡，但已经能拦住 v0 那种综述。

## 来源与时效

三问是入门口令。后面七个问题用来补漏，不替换这三问。
