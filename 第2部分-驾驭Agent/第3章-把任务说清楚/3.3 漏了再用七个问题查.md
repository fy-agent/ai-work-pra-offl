# 3.3 漏了再用七个问题查

## 这节解决什么问题

三问过了，跑出来的文件还是会在边边角角猜。漏掉的通常是同一类：没说材料范围、没说禁区、没说怎么验收。

## 先记住什么

漏了，用七个问题查。每问只答一件事。写不满的格子，就是还会被猜的地方。

| 问 | 你在回答 |
| --- | --- |
| 任务 | 要它做什么？ |
| 背景 | 给谁用？为什么做？看完做什么？ |
| 材料 | 根据什么做？哪些不放进去？ |
| 要求 | 必须做到什么？要能打勾 |
| 边界 | 哪些不能做？不知道怎么办？ |
| 交付 | 最后给我什么文件、多长、什么结构、叫什么名字？ |
| 验收 | 结果出来，哪几项能打勾？ |

这是检查表。不必把「任务、背景、材料」这些标签念给工作台听。你写清楚人话，它就能执行；标签是给你自己查漏的。

两种坏法最常见：

- 「你看着办。」等于没有边界、没有交付、没有验收。
- 堆形容词。「高端、完整、有洞察」打不了勾，工作台只能继续猜你的审美。

## 当场怎么做

1. 打开上一节那张还嫌粗的卡，按七问一行一行补。空着就空着，不要编。
2. 删掉不能打勾的词，换成结果里能看见的句子。例如把「专业一点」改成「决定和待确认分开写，待确认不要写成事实」。
3. 拿两张反例对照，圈缺口，不要修文笔：
   - 反例 A：`这份记录你看着办，弄好就行。`
   - 反例 B：`做一份高质量、全面、有战略高度的汇报，语气专业。`
4. 补完后，不要马上加新功能。先用这张卡跑第二版，看 v1 还猜哪一段。

## 怎么检查

过：七问都有答案；没有「你看着办」；没有只能靠感觉打分的形容词当要求；交付里有文件名。

返工：七问变成七段小作文，读完仍说不出交什么；或边界是空的。

## 常见翻车

把七问当成 Prompt Engineering 课，开始追求「标准模板格式」。模板是给人查的。交出去的可以是一段连贯的话，只要七问都能对上。

要求写了十多条，验收一条没有。做完以后你还是不知道过没过，等于没写验收。

## 最小例子

反例 B 改成能打勾的要求，可能是：

- 一页以内
- 决定、待确认、行动项分三块
- 每条行动有人和日期；没有人的写待确认
- 会议记录里没出现的数字不要写

验收就对着这四条打钩。钩打不上，只改对应那一块，不整篇重写。

## 来源与时效

七问是给职场任务用的检查表，不是某个产品的官方字段。你的工作台如果另有「任务说明」框，把这七问写进去即可，不必改软件设置。
