# 4.4 只读盘点：清单、建议、预览

## 这节解决什么问题

上下文写好了，第一次练习仍不该让它整理真实文件夹。先做只读盘点：它列出看见了什么、建议怎么处理、若要改会改哪里。原件不动。你抽查它看的是不是那份文件。

## 先记住什么

这一趟只要三样，都是新文件：

1. **材料清单**：路径、文件名、它当成什么（原件 / 参考 / 草稿 / 不要碰）
2. **盘点建议**：哪份该留、哪份是旧版、哪份你必须亲自看
3. **变更预览**：假如下一步要整理，会移动或改名哪些；状态写成「未执行」

原件没有被移动、重命名、删除，才算过。建议可以大胆，执行必须等你点头。

抽查：从清单里挑 3 条，自己打开原件，看它写的名字和用途是不是那份。抽到错的，只改清单上错的那几行，不要让它重新「整理整个文件夹」。

## 当场怎么做

1. 建一个练习文件夹，放虚构或你有权使用的几份文件。不要放客户原件和系统备份。
2. 用 4.3 的给、标、限交一次「只读盘点」任务，交付文件自己起名，例如 `材料清单_v1.md`。
3. 打开三样产物。看见「建议删除」「直接移动原件」而预览状态不是「未执行」，立刻停。
4. 抽 3 条路径打开原件。版本号、日期、是不是「勿删」，以你打开的那份为准。
5. 错的只改对应行，另存 v2。换一个更小的文件夹，再跑一遍同一套三问。分类可以变，给、标、限不变。

它若开始改原件：停。把任务改回只读，检查原件还在不在。入门练习不要用「撤销」当计划。

## 怎么检查

过：三样都能打开；抽查 3 条对得上原件；原件仍在原处；删除/移动只出现在未执行的预览里。

返工：只有一份「整理报告」却说已经帮你归好档；或系统类、勿删类文件被标成可删除。

## 常见翻车

清单把所有文件都标「低风险、保留」。那不是盘点，是复读文件名。

把预览写成已经执行。预览的价值是你还能说不。

## 最小例子

李明练习文件夹里有：`月度数据.xlsx`、`上月月报.docx`、`月报_最终.docx`（6 月）、`系统设置-勿删.txt`、`随手记.txt`。

合格清单会写：`月报_最终.docx` 是旧稿，不是本月定稿；`系统设置-勿删.txt` 不给建议、标高风险、不要删；若要移动随手记，只出现在预览表，状态「未执行」。

失败清单一上来建议删除系统设置，并把三个月报都标成当前稿。那 4.3 的「标」和「限」都没生效。

## 来源与时效

只读红线由你的任务写死，不依赖某个产品是否提供只读模式。换工作台时，先用同一套三问跑盘点，再决定要不要让它改文件。
