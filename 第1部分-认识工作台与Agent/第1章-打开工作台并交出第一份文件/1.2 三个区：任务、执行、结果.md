# 1.2 三个区：任务、执行、结果

## 这节解决什么问题

工作台打开以后，屏幕上东西很多。新手容易把左侧菜单翻完，还是不知道任务交到哪、它在干什么、文件从哪打开。

## 先记住什么

先认三个区，别认完所有按钮。

| 区 | 你在这看什么 |
| --- | --- |
| 任务 | 这次交了什么、现在跑的是哪一条 |
| 执行 | 它正在读材料、改文件、还是卡住了 |
| 结果 | 新出现的文件；要打开来看，不要只看预览句 |

界面显示「完成」，只说明它跑完了这一趟。月报合不合格，要在结果区打开文件之后才知道。

Skill、连接器、定时任务今天先别点。那是后话。

## 当场怎么做

1. 打开工作台，先不要打字。
2. 用手指指三个位置：任务列表在哪、执行过程在哪、结果文件在哪。指错就停，翻菜单也找不到「结果」这两个字也没关系，找到「新生成的文件出现的地方」即可。
3. 选一个单独的文件夹当这次的工作区，不要用桌面大杂烩。
4. 看一眼输入框在哪。发送任务通常是把话交给工作台，不是发给同事。
5. 还没写清要交什么之前，先不要点发送。下一节才发月报任务。

## 怎么检查

过：你可以不看说明书，指出任务、执行、结果三个区；并且知道「完成」不等于「文件合格」。

返工：你只能指出输入框，说不出结果文件会出现在哪。

## 常见翻车

对着教程截图找按钮。截图会裁掉字，软件也会改版。认区要认你自己屏幕上的窗口。

把中间滚动的过程日志当成结果。日志说明它在动；交付物是右边或结果列表里那个能打开的文件。

## 最小例子

李明第一次打开工作台，把左边菜单从上点到下，点开了技能市场。十分钟后，月报还是零。

后来他只盯三件事：左边有没有这条「月报」任务，中间是不是还在读 `月度数据.xlsx`，右边有没有出现 `月报_v1.docx`。文件没出来之前，他不离开结果区去研究别的功能。

## 来源与时效

三个区是稳定工作法。各产品把它们叫工作区、会话、线程、输出、Artifacts 都可以，以当天界面为准。不要把旧截图上的英文标签背下来。
