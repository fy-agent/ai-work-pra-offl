# 2.2 先问一句就够的，别升级

## 这节解决什么问题

刚知道 Agent 能采取行动，就容易什么都丢给工作台：查一个词、改一个错别字、问「周报和日报有什么区别」。简单问题被升级成一次跑文件的任务，又慢又难查。

## 先记住什么

不是所有任务都该 Agent 化。先问三句：

1. 我只是在问一个问题吗？
2. 需要它替我采取行动、改到材料或环境里吗？
3. 中间要根据结果再决定下一步吗？

对应三档：

| 档 | 什么时候用 | 你要看见什么 |
| --- | --- | --- |
| 问 | 只要解释、对比、给个说法 | 一段你能判断对错的回答 |
| 做 | 要它读材料、改文件、整理出产物 | 能打开的文件或明确的修改 |
| 边做边决定 | 做完一步，得看结果才能定下一步 | 过程中至少有一次停下来让你看 |

问得出来，就别让它做。要动手，再交给工作台。工作台也不是默认比聊天「更高级」，只是更适合要行动的任务。

## 当场怎么做

给下面六个任务各标一档，并写半句理由。标「不确定」也行，但要写缺什么信息。

1. 「周报和日报有什么区别？」
2. 「把这份会议记录整理成一页纪要。」
3. 「这个缩写在我们组里是什么意思？」
4. 「对照这张表和这份月报，把对不上的数字标出来。」
5. 「帮我准备明天下午的项目复盘会。」
6. 「这句话语法对不对？」

写完后换成你自己上周的一件真事，再走三问，给出判断。不要为了显得厉害，全部标成「边做边决定」。

## 怎么检查

过：六个任务都有档和理由；至少有一个标成「问」；你自己那件也能说出为什么不升级或为什么要行动。

返工：六个全是 Agent；或理由是「用工作台比较高级」。

## 常见翻车

把「问」理解成低级，「做」理解成高级。查天气、问定义、要一个比喻，用聊天更快。非要走工作台，它可能去翻文件夹、写一份「调研报告」，你还得检查这份没人要的报告。

另一头：明明要改文件，却在聊天里来回要「再专业一点」，始终没有产物。

## 最小例子

李明有三件事：

- 问同事「OKR」怎么读：问一句就够。
- 把本周任务表压成一页周报：要做，因为要读表、交文件。
- 月报数字和表对不上，要先标异常再决定改哪一段：边做边决定，中途要他看一眼再继续。

他把第一件丢进工作台，等了两分钟，得到一份「OKR 概念说明.docx」。没人要这份文件。

## 来源与时效

三档是判断练习，不是产品模式名。你的软件里如果有只读、计划、执行之类入口，怎么选放到以后再写，本节省略。
