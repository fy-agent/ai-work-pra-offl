# 2.1 看、决定、做、再看

## 这节解决什么问题

刚会交文件的人，容易把区别理解成：聊天短、工作台长；或者「会不会生成文件」。真正差在有没有围绕目标去采取行动。

## 先记住什么

给同一个任务：

> 帮我准备明天下午的项目复盘会。

聊天 AI 常常直接回答：复盘可以分三部分，先讲目标，再讲进展，最后讲风险。你听完，材料还是要自己去翻。

Agent 会为这个目标采取行动：去读你给的项目材料，对照计划和本周记录，抽出未完成项，整理成会前材料，并把对不上的地方标出来。文件是行动的结果之一，不是定义。

多出来的四步，今天只记这四个字：

**看 → 决定 → 做 → 再看**

- 看：先弄清目标和手上有什么
- 决定：下一步该读哪份、问哪句、还是开始改文件
- 做：调用工具，动到工作台外面的材料
- 再看：根据刚才的结果，决定继续、改方向或停

没有生成文件，也可能仍在做事。关键是它有没有为了目标与外部环境发生行动。

## 当场怎么做

1. 把「帮我准备明天下午的项目复盘会」丢给普通聊天，看它是不是主要在教你怎么开。
2. 同一句话交给工作台，并给它两份虚构材料：本周任务表、上次会议纪要。看它是不是开始读材料、抽未完成项。
3. 把两边发生的事各写一句：一边是回答，一边是开始行动。
4. 用四步回头套一下工作台刚才做的事。套不上「做」和「再看」，就还是一次问答。

## 怎么检查

过：你能用「看、决定、做、再看」讲述刚才那次任务，并且不把「有没有文件」当成唯一标准。

返工：你的结论是「Agent 就是更高级的聊天」或「Agent 就是会生成文件」。

## 常见翻车

看见工作台最后只回了一句话，就判断它没在做事。

反例：你问「明天出门要不要带伞」。它去查了天气，再告诉你带伞。没有 Word，但有「看天气 → 决定要不要提醒你 → 查 → 再看要不要补充」。这仍然是在为目标采取行动。

反过来：它写了很长一份「复盘方案」，但没读你给的材料，方案里的事项在纪要里对不上。那是一篇回答，即使保存在文件里也一样。

## 最小例子

李明明天下午要开项目复盘。聊天工具给他一份万能议程。工作台读了他放进去的「本周任务.md」和「上次纪要.md」，列出三条未完成，其中一条在两份材料里说法不一致，标了待确认。

会前他要的是后一种：带着材料进会议室，而不是带着一篇结构漂亮、事实对不上的作文。

## 来源与时效

「看、决定、做、再看」是给入门用的叫法。产品文档里可能写成 Agent、工具调用、多步任务。主文用四个字，不绑某个厂商的术语表。
