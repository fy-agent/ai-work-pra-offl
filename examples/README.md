# 离线练习材料

这里的文件全部是虚构教学材料，可以复制到一个单独的练习文件夹里使用。它们不是业务原件，也不代表任何产品的当前规则。

## 建议用法

1. 把本目录复制成一个新的练习文件夹，不要直接在仓库根目录生成结果文件。
2. 每次只把当节要求的输入材料交给工作台；`expected-facts.md` 要留到生成后再看。
3. 结果写入练习文件夹里的新文件，不覆盖这些输入。
4. 用章节里的检查项和 `expected-facts.md` 对照，未知仍保留为待确认。

## 材料地图

| 材料 | 用途 | 对应主线 |
| --- | --- | --- |
| `monthly-data.csv` | 月报数字，含一列不能当作数字的自由文本 | 第 1–6 章 |
| `previous-report.md` | 上月结构样例，数字不能抄 | 第 1–6 章 |
| `meeting-notes.md` | 决定、待确认和负责人 | 第 3、8、10、12 章 |
| `weekly-log.md` | 一周工作记录，含结果与未完成项 | 第 7、10、12 章 |
| `attendee-list.csv` | 缺日期、重复人名的异常名单 | 第 9 章 |
| `product-fact-sheet.md` | 事实底稿，价格和限制条件以此为准 | 第 19 章 |
| `expected-facts.md` | 复核用基线，不要在首次运行时提供给工具 | 第 1–20 章 |

## 公开仓边界

材料包只提供可复跑的输入和人工复核基线，不提供账号、密钥、真实客户资料或可直接外发的成品。结果是否通过，仍要由人按章节检查；材料包本身不等于课程批准或工具验收。
