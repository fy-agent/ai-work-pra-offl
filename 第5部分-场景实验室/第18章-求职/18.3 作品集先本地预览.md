# 18.3 作品集先本地预览

## 这节解决什么问题

简历提到作品，工作台直接生成要上线的网页，还塞了未授权截图。选修到这里，作品集只做到本地能打开、隐私检查过。公开上线另批。

## 先记住什么

先一页项目：要证明哪一件事、用哪份本地文件、哪些图不能用。

未授权截图、失效图、别人的客户数据，都是失败版。

本地预览过关，不等于可以公开。公开是另一次批准。双工具都先本地看，不先备案域名。

## 当场怎么做

1. 只选一个项目，例如「一页周报怎么做出来的」。
2. 材料只用你有权使用的脱敏文件。
3. 任务：生成本地可打开的一页说明（HTML 或 Markdown 预览都行）；附隐私检查表：无手机号、无客户名、无内部路径。
4. 打开预览。坏的那一页只改那一页。第二项目同样先本地。

不要让它「发布到网上」。

## 怎么检查

过：本机能打开；证据回得了源；隐私表打钩；没有外链到未授权图。

返工：页面很炫，图是搜来的商品照；或已经生成上传脚本。

## 常见翻车

把工作台聊天记录整页贴上去。记录里常有内部路径和他人姓名。

## 最小例子

项目页只放：任务卡摘要、周报 v2 的结构截取（数字已是虚构练习数）、三步核对。不放真实公司名。公开按钮不出现。

## 来源与时效

静态站点工具、导出格式会变。本地先看、公开另批，这条不变。

## 状态

候选读本。不是已批准课程。
