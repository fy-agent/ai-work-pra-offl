# 10.1 链接堆不是简报

## 这节解决什么问题

要做决定了：活动还办不办、人数够不够。工作台交来一串链接和「据报道」。点开有的 404，有的对不上你的问题。那不是简报，是链接堆。

## 先记住什么

简报要改变哪个判断，开头就写。这一页不是资料库。

先有来源账本，后有结论。账本至少：来源是什么、能不能打开、它能证明什么、不能证明什么、状态（已核 / 仅线索 / 打不开）。

打不开的，不能写成「据报道已证实」。缺口必须留着。

## 当场怎么做

1. 写清要判断的那一句，例如「本周五活动是否照常」。
2. 给 3 份你有权使用或公开可打开的材料，不要整网乱搜当课堂。
3. 任务：先做来源账本，再写一页简报；每句结论能回一条来源；打不开的标出来，不要编。
4. 抽三处结论回原文。回不去就删句，不要补形容词。

不要用未授权的内部政策全文。可用你自己写的虚构通知、公开文档、本指南里的假材料。

## 怎么检查

过：简报开头有要判断的问题；账本里每条有状态；至少一处缺口还在。

返工：全文都是确定口吻；或链接堆没有一句判断。

## 常见翻车

搜索摘要当事实。摘要不能代替打开原文。没打开就标未核验。

## 最小例子

三份材料：群通知「周五照常」、场地短信「再确认」、报名表 36 人。合格简报：人数有表；时间以群通知为准；场地仍待确认，不能写「场地已落实」。失败简报：三句话都「已就绪」，场地那条其实没打开。

## 来源与时效

事实 / 推断 / 未知 分开，是稳定工作法。具体要不要做文献格式，职场入门不要求。

## 状态

候选读本。不是已批准课程。
