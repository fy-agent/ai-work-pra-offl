# 11.2 先页纲，先做 3 页

## 这节解决什么问题

页纲没定就出幻灯，后面每改一个主张都要重排版。先交页级任务表，再做 3 页，打开检查。

## 先记住什么

页级任务表一行一页：页码、主张、必须出现的事实、不要出现的内容、来源。

3 页样生成后立刻打开。检查顺序和第 6 章一样：数字、日期、结论，再看挤不挤、能不能改。

第二份材料只做 2 页样，练的是迁移，不是再做一套品牌手册。

## 当场怎么做

1. 把提纲 6–8 页收成今晚 3 页。其余写「未做」。
2. 任务带上任务表，禁止增加装饰页、目录页、结束页金句。
3. 生成后打开，站着讲一遍：讲不下去的记下页码。
4. 主张回源。回不到的那页进下一节只改那一页。

## 怎么检查

过：任务表和 3 页能对上；未做的页没有被塞进来；打开过，不是只看缩略图。

返工：多了很多「谢谢聆听」；或 3 页主张和任务表不是同一组。

## 常见翻车

为了对称，凑成 10 页。对称不是今晚的验收。

## 最小例子

任务表第 2 页：「人数 36，来源报名表，不要写充分报名。」小样如果写成「报名踊跃」，这一页失败，即使排版很好。

## 来源与时效

3 页是入门小样数量，不是公司汇报必须 3 页。样张通过再批量，这一句不变。

## 状态

候选读本。不是已批准课程。
