# 11.1 图片幻灯和能改的小样

## 这节解决什么问题

提纲有了，工作台给一套很漂亮的幻灯片图。字在图里，改一个数字要重出图。会上讲到第三页讲不下去，也改不了。你要的是能打开、能改、能站着讲的小样，不是海报。

## 先记住什么

先确认样：3 页就够。每页一句主张，主张回得了提纲。能改，是指你能改文字和数字，不是指动画多。

图片幻灯可以当配图参考，不能当交付。交付是可编辑文件，或至少是页面规格：每页标题、主张、要出现的数字、来源。

导不出 PPT 时，交页面规格。不要假装已经有一份稳定 pptx。

## 当场怎么做

1. 从提纲里只挑 3 页：今晚能讲完的那 3 页。
2. 任务：按页纲生成小样；每页主张回源；不要把字做成整页大图。
3. 打开文件。改一个数字试：改不了，这页不合格。
4. 字挤到页外、主张和数字打架，这页不能交。

不要一上来要 20 页全套。样张过了，再考虑后面页。

## 怎么检查

过：3 页能打开；你改得动字；每页主张能回提纲；没有外发。

返工：只有导出的长图；或 20 页里你只看了封面。

## 常见翻车

「先出效果再换文字」。效果把字焊死了，文字就换不了。顺序反了。

## 最小例子

第 1 页主张「周五照常办」。小样标题就是这句，人数 36 可改。失败页是一张夜景图加艺术字，36 写在图上，选不中。

## 来源与时效

可编辑性以你当天软件为准。有的工作台只给 HTML 或 PDF。PDF 当确认样可以，当最终可改交付不行，要在规格里写明。
