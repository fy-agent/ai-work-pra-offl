# 8.2 筛、分、写：决定不是建议

## 这节解决什么问题

转写很长。直接让它「提炼要点」，寒暄和拍板会挤在一起。先筛掉不能执行的话，再分类，再写成一页。

## 先记住什么

做法五个字：筛 → 分 → 写 → 核 → 改。

先丢掉寒暄、口头禅、重复确认「嗯嗯好的」。留下的句子分成四类：

| 类 | 原话大概长什么样 | 写成纪要时 |
| --- | --- | --- |
| 决定 | 就这样、定了、按这个走 | 已拍板，能回原句 |
| 行动 | 谁去问、谁去改、谁去发 | 动作要看得见 |
| 待确认 | 再说、问问、还没批 | 保持待确认，不升级 |
| 必要背景 | 不写会听不懂的事实 | 极短，能回转写 |

没拍板的，别写成决定。「建议先挂着」不是决定。

「尽快」不是截止日期。原话没日期，格子里写待确认，不要编一个周五。

## 当场怎么做

1. 任务里写清四类，并禁止把建议写进决定。
2. 让它先标再写：可以先出带标签的半成品，你看过分类再填成一页。
3. 打开 v1，抽三条决定或行动，回转写找原话。找不到就改类，不要改得更顺。
4. 只改写错的那几条。另存 v2。

长转写也不要在入门任务里让它「分段摘要三次」。一页、四类、回源，够了。

## 怎么检查

过：决定栏里每条能回原话；建议没有混进决定；缺的人和日期是待确认，不是空白被填满。

返工：分类只存在聊天里，一页正文仍是散文；或「尽快」变成了具体日期。

## 常见翻车

把主持人总结当成全部决定。总结里常混着愿望。以转写里明确拍板的句子为准。

## 最小例子

原话：「预算还没批，先别写进通知。」合格纪要进待确认或决定「通知里不写预算」。失败纪要写成「预算工作已安排」。

原话：「你帮我问一下场地。」行动有动作，人若在转写里含糊，写成待确认，不要指定「李明」。李明是我们例子里的人，不等于会上点了名。

## 来源与时效

四类是入门分类。你们若还要「议题 / 结论 / 未决」，映射过去即可，不要同时维护两套互相打架的栏。
