# 8.3 行动表要有人、期、动作

## 这节解决什么问题

纪要看懂了，周一还追不到人。因为行动埋在段落里，或一行里塞了两件事。从表上要能看见：谁、做什么、哪一天。

## 先记住什么

行动表是另一份文件，格子是给人追踪的，不是把纪要再排版一次。

一行只写一个动作。并在一句里的「改海报并问场地」，拆成两行。

三列缺一就先标待确认：

| 列 | 缺了会怎样 |
| --- | --- |
| 谁 | 周一不知道找谁 |
| 做什么 | 知道找谁，不知道要什么 |
| 哪天 | 只能说尽快 |

建议先挂着。没人接下，就不要进正式表。正式表只放已确认或明确点名的动作。

## 当场怎么做

1. 只用上一节那页纪要当材料，不要把整份转写再塞一遍。
2. 任务写清：抽出行动，一行一件，人、期、动作分列；没有的写待确认；不要编周五。
3. 先预览几行，对人、期、动作分别回纪要原文。
4. 打开表，数行数：纪要里几条行动，表里就应该对得上，不能无中生有。

原件纪要只读。表是新文件，例如 `行动表_v1.csv` 或 `.xlsx`。

## 怎么检查

过：每行能看见动作；缺的格子是待确认；没有把两件并一行；没有把建议行混进正式表。

返工：表很全，但「相关人员 / 本周内」占了很多格；或行数明显多于纪要里的行动。

## 常见翻车

空格被填成「周五」。转写没说周五。这是编造，和第 7.3 节把准备写成完成是同一类错。

## 最小例子

纪要：「通知改期——已发」「场地——待确认谁去问」。表里第一行：谁=（记录已写发出的人，若没有则待确认），做什么=确认通知已到报名者，哪天=会后当日（若原话有）。第二行场地：谁=待确认，哪天=待确认。不要把第二行写成「李明 周五前落实场地」。

## 来源与时效

三列是最低追踪集。你们若还要状态、优先级，后加，不要在入门第一张表上铺十列。

## 状态

候选读本。不是已批准课程。
