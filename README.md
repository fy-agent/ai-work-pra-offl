# 职场 AI 实践指南 · 离线存档

仓名 `ai-work-pra-offl`：`work` 职场，`pra` 实践，`offl` 离线。

给年轻人和职场人看的自学手册。目标不是多认识几个按钮，而是：拿自己的材料，让 AI 工作台交出一份能打开的文件，你再检查、改一处、下次还能照着做。

## 先说清楚

这不是正式课程，不是招生简章，也不是任何 AI 产品的官方说明书。

正文里的方法仍在试教，状态是候选读本。读完不等于上过课，也不等于某个工具已经替你通过验收。

练习只用你有权使用的材料，或者本指南里的虚构例子。不要拿真实客户资料、未授权文件、账号密码来练。本仓库不提供共享账号，不代管凭证，不教自动发送、自动付款或自动发布。

## 这本指南在讲什么

六件事，按这个顺序：

1. 聊天回答和交文件，不是一回事。
2. 一句话「帮我做一下」，通常不够当任务。
3. 生成一次不算完，还要看、查、改。
4. 读起来顺，不等于数字和事实对得上。
5. 同一件事做成过，才值得写成可复用的做法。
6. 先选任务，再选工具；不要默认用最贵的模型。

五部分都已有正文：认识工作台、驾驭任务、交职场文件、给方法起名、选修场景。未列出的章不要理解成还有空壳。

## 怎么离线读

把本仓库放到电脑上，用任何 Markdown 阅读器或编辑器打开 `README.md`，按目录点进去。

- 一节一个文件，可以全文搜索。
- 不需要外网才能读正文。
- 产品入口、价格、额度会变，不写死在主文，见 [附录 A](附录/A-入口与额度更新卡.md)。

建议阅读顺序：[怎么用这本指南](00-怎么用这本指南.md) → 第 1–4 部分主线 → 第 5 部分只选本周真会碰到的一节。不要从菜单巡游开始，也不要九个选修一起做。
