# 16.2 先审计再接入外部系统

## 这节解决什么问题

左栏有「专家·技能·连接器」。还没看权限，就授权邮箱、网盘、聊天软件。接入成功不等于安全。

## 先记住什么

MCP / 连接器是让工作台接到外部系统的一种方式。名字会变。入门先会审计：

- 读什么
- 写什么
- 谁授权
- 怎么断开

权限范围没看就授权，是失败版。每项权限要能回官方说明。第二个连接器可以只填审计表、不接入。

## 当场怎么做

画一张四格卡再决定接不接。填不出「怎么断」，就不要接。入门课堂不接真实付款、真实发送。

## 怎么检查

过：四格都有字；你能说出断开入口在哪一类设置里（当天再找一次）。

返工：只关心「连上了没」。

## 常见翻车

用演示账号的成功，代替你自己的最小权限。演示权限往往比你该给的大。

## 最小例子

只为了读一个公开网页就打开「发消息」权限。审计不合格。能读公开页的连接，不应带发送。

## 来源与时效

连接器清单、OAuth 弹窗以当天官方为准。主文只保留审计四格。
