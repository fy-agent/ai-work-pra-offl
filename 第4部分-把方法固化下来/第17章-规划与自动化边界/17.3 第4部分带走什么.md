# 17.3 第 4 部分带走什么

## 这节解决什么问题

名字都起过了。出门不是一张概念表，而是你能解释一次自己的任务：哪是 Loop，哪是工具，哪该做成 Skill，哪绝不能自动。

## 先记住什么

第 1–3 部分做过的，这里只是命名：

- 看、决定、做、再看 → Loop
- 读和写 → Tools
- 可交接的重复方法 → SOP / Skill
- 选进空间的材料 → Context
- 外部系统 → 先审计再接入
- 定时 → 手跑两次之后，且不做删除付款发布

选修场景（求职、内容、活动）还没写。没有那些章，你已经能把任意一件合法材料走完：任务卡 → 空间 → 工具 → 核对 → 一页产物。

## 当场怎么做

用一张空白复盘卡，填你自己上周的一件事。四栏都有事实。自动化那一行允许写「暂不」。

## 怎么检查

过：卡上没有「赋能」「闭环」；每一栏都能指回文件或屏幕。

返工：只会背英文词。

## 常见翻车

把本指南当成官方手册。它是候选读本。产品按钮以你当天窗口为准。

## 最小例子

复盘卡可以很短：任务=虚构月报；工具=读取失败；产物=无；反馈=停问路径。这张卡合格。一份没有原件的精美月报不合格。
